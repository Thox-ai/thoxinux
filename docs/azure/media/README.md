# ThoxOS Ginux introduction and demo media

ThoxOS Ginux Azure Compute Edition is an engineering candidate combining a customized independent Rust kernel, a source-pinned build, a compiled EFI, native/Docker recipes and an Azure deployment kit. Azure boots an Ubuntu Gen2 host; QEMU TCG runs the Ginux guest. This package provides a concrete research and evaluation foundation for the THOX operating-system layer.

The kernel and build acceptance belong to source `0c91c839cf19b5171b6efea86cffc4b91e398467`. This documentation delivery adds media and email continuity without rebuilding or changing the kernel. Existing package hashes and source receipts remain valid for that original source revision.
